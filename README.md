Утилита на Python для автоматического пакетного переименования MP3-файлов на основе их метаданных (ID3-тегов).

---

## Описание

Скрипт сканирует папку `input`, извлекает из каждого MP3-файла информацию о названии трека и исполнителе, после чего переименовывает файл по единому шаблону:

```text
{Название трека} - {Исполнитель}.mp3
```

## Инструкция

1. Поместите MP3-файлы, которые хотите переименовать, в папку `input/` в корне проекта (если папки ещё нет, запустите скрипт один раз — он создаст её автоматически).
2. Запустите скрипт.
3. Скрипт обработает все файлы `.mp3` в папке `input` и выведет результаты в консоль.
